# Егор — ведущий мероприятий в Ижевске

Адаптивный сайт на FastAPI, Jinja2, CSS и небольшом JavaScript. Серверная отрисовка даёт быструю загрузку и понятные поисковикам страницы без сборки фронтенда. Заявки сохраняются в SQLite; успешный ответ API означает, что запись добавлена в базу.

Основной акцентный цвет — `#B91B39`. Крупные заголовки набраны локальным шрифтом Seenonim, остальной текст — Evolventa. Seenonim создан Маргаритой Колмыковой и распространяется по CC BY; условия находятся в `app/static/fonts/Seenonim-README.txt`. [Evolventa](https://evolventa.github.io/) создана Александром Кузнецовым и доступна по GPLv2/LPPL. Файлы шрифтов находятся в `app/static/fonts/` и загружаются с самого сайта.

## Локальный запуск

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Откройте `http://127.0.0.1:8000`. Для проверки: `.\.venv\Scripts\python.exe -m pytest -q`. На Linux используйте `python3 -m venv .venv` и `.venv/bin/python`.

## Редактирование сайта

Все контакты, услуги, отзывы и пути к медиа находятся в [app/content.json](app/content.json). Файл можно редактировать в текстовом редакторе. После изменения перезапустите сервер. Для фотографий положите файлы в `app/static/media/` и укажите путь вида `/static/media/hero.webp`. Желательно подготовить WebP/AVIF и размеры под разные экраны; для первого экрана — файл до 300 КБ, для галереи — до 200 КБ на кадр. Не добавляйте вымышленные отзывы или фотографии.

Поля `hero_image`, `portrait_image`, `video_url`, `gallery`, `reviews` изначально пусты. Пример галереи: `[{"src":"/static/media/event-1.webp","alt":"Егор ведёт корпоратив в Ижевске"}]`. Пример отзыва: `[{"text":"...","name":"...","date":"...","source":"https://..."}]`. В `video_url` нужна ссылка на встраиваемый плеер; видео загружается после нажатия.

Укажите настоящие `phone`, `vk` и `telegram`. Пустые контакты не показываются на странице. Тексты разделов сейчас находятся в `app/templates/index.html`; их можно менять в этом файле без знания Python. После редактирования шаблона перезапустите сервер.

## Заявки и данные

Форма отправляет POST `/api/leads`. Сервер проверяет поля, обязательное согласие, скрытое поле от ботов и ограничивает число заявок с одного IP до пяти в час. Данные сохраняются в SQLite по пути `DATABASE_PATH` (локально `data/leads.sqlite3`). К базе должен иметь доступ только владелец сервера. Для просмотра заявок можно использовать SQLite Browser или команду `sqlite3 data/leads.sqlite3 "SELECT * FROM leads ORDER BY id DESC;"`. Резервируйте эту базу регулярно. Уведомления по почте или в мессенджер пока не подключены: для них нужны реальные адрес/токен и выбранный сервис. Заявки находятся в базе, даже если уведомление не настроено.

## Аналитика, SEO и документы

В `.env` задайте `YANDEX_METRIKA_ID` после создания счётчика на аккаунте владельца. Метрика загружается только после выбора «Разрешить» в баннере. Подготовлены цели `phone`, `vk`, `telegram`, `cta`, `lead_sent`. UTM-метки источника, канала и кампании сохраняются вместе с заявкой. Яндекс Вебмастер подключается владельцем после публикации и подтверждения домена. `robots.txt`, `sitemap.xml`, Title, Description и Open Graph уже подготовлены. Добавьте реальную фотографию для Open Graph перед публикацией.

Страница `/privacy` содержит только заготовку. **До публикации** заполните реквизиты оператора, сроки хранения и порядок удаления данных; проверьте текст с юристом. Определите фактическое использование cookies и Метрики, затем оформите корректное информирование и согласие. Домен, хостинг, Метрика и Вебмастер должны быть зарегистрированы на владельца сайта.

## Деплой на Linux VPS

Понадобятся Docker с Compose, домен с A-записью на IP сервера и открытые порты 80/443. Скопируйте проект на сервер, создайте `.env` по `.env.example`, укажите `DOMAIN` и `SITE_URL=https://DOMAIN`. При наличии счётчика добавьте `YANDEX_METRIKA_ID`. Затем выполните `chmod +x deploy.sh && ./deploy.sh`. Скрипт проверяет конфигурацию, поднимает FastAPI и Caddy, создаёт таблицу заявок и проверяет `/health`. Caddy получает HTTPS-сертификат автоматически, когда DNS указывает на сервер. Повторный запуск не удаляет базу. Резервируйте Docker volume `leads_data` перед изменениями на сервере.

## Что требуется до публикации

- Настоящие фотографии Егора и мероприятий, видеовизитка, отзывы с разрешения клиентов.
- Телефон, VK и Telegram в `app/content.json`.
- Окончательный текст политики, данные оператора, решение по cookies и аналитике.
- Домен, доступ к VPS, аккаунты Яндекс Метрики и Вебмастера на имя владельца.
- Проверка тестовой заявки в базе и мобильного отображения с реальными медиа.
